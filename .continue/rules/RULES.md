# 🛡️ AI Coding Rules

## 1. 제약 조건 (오류 원천 차단)
- **코드 임의 창작 금지**: 제공된 파일에 없는 함수, 변수, 라이브러리를 임의로 만들어서 쓰지 마라.
- **전체 출력 금지**: 요청한 특정 함수나 클래스 내부만 수정해라. 파일 전체를 새로 짜서 출력하지 마라.
- **스타일 유지**: 기존 코드의 네이밍 규칙(snake_case 등)과 들여쓰기를 100% 그대로 유지해라.

## 2. 출력 포맷 (속도 및 램 최적화)
- **설명 금지**: 인사말, 서론, 코드 문법에 대한 장황한 설명은 일절 생략한다.
- **코드 중심**: 오직 변경되거나 추가된 코드 블록만 출력해라.
- **최종 요약**: 코드 블록 아래에 바뀐 핵심만 딱 1~2줄로 요약해라.
